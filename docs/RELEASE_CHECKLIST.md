# Lista przed wydaniem

- [ ] Wyjaśniona pisemna zgoda na modyfikację i dystrybucję w wymaganym zakresie.
- [ ] Zweryfikowane prawa do głosów, tekstów, użytych fragmentów audio i zależności.
- [ ] Paczka nie zawiera oryginalnych archiwów, pełnych wyodrębnionych dialogów, kluczy ani danych konta.
- [ ] Zdefiniowany build Steam, numer wersji i rzeczywisty zakres pokrycia.
- [ ] Zamknięta beta na innej instalacji Windows / Steam.
- [ ] Test całego przejścia M → Q po naprawie markerów.
- [ ] Sprawdzone instalowanie, aktualizacja, rollback i odinstalowanie.
- [ ] Zachowanie innych modów i zapisów gry potwierdzone w testach.
- [ ] Gotowa instrukcja, znane problemy, changelog, credits i właściwe licencje.
- [ ] Końcowa paczka ma stałą wersję i sumę SHA-256.
- [ ] Repozytorium, indeks i metadane commitów przeszły kontrolę prywatności.
- [ ] Materiały zawierające syntezę głosu mają wymagane oznaczenia na platformie dystrybucji.
- [ ] Raz opublikowane pliki wersji pozostają niezmienne; poprawki otrzymują nowy numer.

Lista jest otwarta. Umieszczenie kodu na GitHubie nie oznacza spełnienia wszystkich warunków wydania paczki audio.
