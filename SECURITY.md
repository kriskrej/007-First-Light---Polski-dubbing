# Bezpieczeństwo

Nie publikuj kluczy, tokenów, danych kont ani szczegółów umożliwiających wykorzystanie podatności w otwartym zgłoszeniu. Skorzystaj z prywatnego zgłoszenia bezpieczeństwa GitHuba, jeśli jest włączone, albo kontaktu z profilu autora.

W przypadku ujawnienia sekretu najpierw go unieważnij u dostawcy. Samo usunięcie pliku lub commita nie unieważnia klucza.

Instalator powinien odmawiać pracy przy niezgodnym stanie gry, zmienionych sumach lub nieznanych plikach innych modów. Nie należy omijać tych zabezpieczeń. Przed użyciem sprawdź źródło pobrania, numer wersji i sumę SHA-256 paczki.

Publiczne wydanie binarne jest nadal w przygotowaniu. Nie ma jeszcze zadeklarowanego okresu wsparcia ani listy wspieranych wersji binarnych.
